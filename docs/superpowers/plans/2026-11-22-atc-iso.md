# ATC Iso Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ứng dụng local trên Mac quét quảng cáo đối thủ trên ATC mỗi ngày bằng Chrome hồ sơ riêng, lưu dữ liệu + ảnh, hiển thị web màn hình ngang, đồng bộ GitHub.

**Architecture:** Node ESM. `src/atc.js` (thuần: dựng yêu cầu, đọc phản hồi), `src/store.js` (tệp JSON trong `data/`), `src/scanner.js` (điều phối, nhận client tiêm vào), `src/browser.js` (Playwright + Chrome thật), `src/server.js` + `web/` (giao diện), `src/sync.js` + `ops/` (git, launchd).

**Tech Stack:** Node ≥ 20, `playwright-core` (channel `chrome`), `node:test`, không framework web (http gốc, HTML/CSS/JS thuần).

**Spec:** `docs/superpowers/specs/2026-11-22-atc-iso-design.md`

## Global Constraints
- Không lách captcha, không xoay IP, không đổi user-agent; gặp chặn là dừng cả lượt (`BlockedError`).
- Khoảng cách giữa hai lượt gọi ATC ≥ 8000 ms + dao động ngẫu nhiên 0–4000 ms.
- Hồ sơ Chrome: `<root>/chrome-profile` (không dùng hồ sơ mặc định của người dùng).
- Cổng web `4317`, nghe `0.0.0.0` (máy cùng wifi dùng được; đổi bằng ATC_HOST).
- Mọi chữ hiển thị tiếng Việt; không chữ kỹ thuật trên giao diện.
- Lần đầu tối đa 5 trang × 40 mẫu/đối thủ; lần sau dừng khi một trang không có mẫu mới.
- "Đang chạy" = lastShown ≥ (lúc quét − 2 ngày); "Mới" = firstSeenByUs trong 24 giờ.
- Mọi ghi tệp JSON: ghi tệp tạm rồi rename (không hỏng tệp khi sập giữa chừng).

## Review Focus
- Tên miền dán kèm `https://`, `www.`, đường dẫn, chữ hoa → chuẩn hoá về `example.com` (Task 1 test `parseWatchInput normalizes`).
- Phản hồi ATC là HTML/302 về `google.com/sorry` hoặc mã 429 → `BlockedError`, lượt quét dừng, nhật ký `blocked`, dữ liệu cũ giữ nguyên (Task 1, Task 2 tests).
- Mẫu không có ngày cuối hoặc không có xem trước → vẫn lưu, `image:null`, không sập (Task 1 test `parseCreatives tolerates missing fields`).
- Bấm "Quét ngay" khi đang quét → không chạy lượt thứ hai (khoá tệp) (Task 2 test `lock prevents concurrent scan`, Task 3 test POST /api/scan trả 409).
- Thêm trùng đối thủ trong một hồ sơ → trả đối thủ cũ, không nhân đôi (Task 1 test `addWatch dedupes`).

### Task 1: lõi ATC + kho dữ liệu
**Files:** Create `src/atc.js`, `src/store.js`, `tests/atc.test.js`, `tests/store.test.js`.

**Interfaces — Produces:**
- `atc.js`: `RPC_BASE = "https://adstransparency.google.com/anji/_/rpc"`; `class BlockedError extends Error`;
  `parseWatchInput(str) -> {type:"domain"|"advertiser", value}` (ném `Error("Không nhận ra tên miền hoặc link nhà quảng cáo")`);
  `buildSearchCreativesReq({watch, pageToken=null, pageSize=40}) -> object` (đúng dạng trong spec, có vùng nếu `watch.region`);
  `parseCreatives(json) -> {ads: RawAd[], nextToken: string|null}`, `RawAd = {creativeId, advertiserId, advertiserName, domain, format, previewUrl, imageUrl, firstShown, lastShown, detailsUrl}` (ngày ISO hoặc null);
  `parseSuggestions(json) -> Array<{type:"advertiser",id,name,country}|{type:"domain",value}>`;
  `isBlockedResponse({status, url, text}) -> boolean`; `slugify(str) -> string`.
- `store.js`: `createStore(root) -> Store` với
  `listProfiles()`, `addProfile(name) -> Profile`, `getWatchlist(pid)`, `addWatch(pid, input, region=null) -> Watch`, `removeWatch(pid, wid)`,
  `allWatches() -> Watch[]` (bỏ trùng theo type+value+region), `getAds(wid) -> AdsFile|null`,
  `mergeAds(watch, rawAds, now) -> {file, newIds}` (giữ `firstSeenByUs` cũ, cập nhật lastShown, ghi tệp),
  `setAdImage(wid, cr, relPath)`, `appendScanLog(entry)` (giữ 30), `getScanLog()`,
  `listAdsForProfile(pid, {filter="all", q="", format=""}, now) -> Array<Ad & {watchId, watchLabel}>` sắp theo firstSeenByUs giảm dần,
  `imagesDir() -> string`. Watch id = `slugify(value)` (+ `-r<region>` nếu có).

- [ ] Viết test: `parseWatchInput normalizes` (`"https://WWW.Gymshark.com/x?y"` → `{type:"domain",value:"gymshark.com"}`; `"https://adstransparency.google.com/advertiser/AR123?region=US"` → `{type:"advertiser",value:"AR123"}`; `"AR016"` → advertiser; `"abc"` ném lỗi);
  `buildSearchCreativesReq` cho domain/advertiser/token/region; `parseCreatives` trên fixture (đúng số mẫu, ngày ISO từ giây, `format` từ 1/2/3, `imageUrl` rút từ `<img src>`), `parseCreatives tolerates missing fields`;
  `isBlockedResponse` (302 sorry, 429, HTML → true; JSON 200 → false);
  store: `addWatch dedupes`, `mergeAds` hai lần (lần 2 không đổi firstSeenByUs, `newIds` rỗng), lọc new/running/stopped với `now` cố định, ghi nguyên tử.
- [ ] Chạy `npm test` → FAIL. Viết mã. Chạy lại → PASS. Commit.

### Task 2: quét + Chrome
**Files:** Create `src/scanner.js`, `src/browser.js`, `src/lock.js`, `bin/scan.js`, `tests/scanner.test.js`.
**Interfaces — Consumes:** Task 1. **Produces:**
- `Client = { rpc(method:string, req:object) -> Promise<object>, captureImage(ad:RawAd, destNoExt:string) -> Promise<string|null>, close() }`; `rpc` ném `BlockedError` khi bị chặn.
- `runScan({store, client, now=()=>new Date(), log=console.log}) -> Promise<{status:"ok"|"blocked"|"error", watched, newAds, error?}>` — phân trang theo luật Global; ảnh chỉ chụp cho mẫu mới; ghi `appendScanLog`.
- `withLock(lockPath, fn)` — ném `Error("ĐANG_QUÉT")` nếu khoá còn sống (pid còn chạy, < 3 giờ).
- `openChromeClient({profileDir, minDelayMs=8000, jitterMs=4000, headless=false}) -> Promise<Client>`: `chromium.launchPersistentContext(profileDir, {channel:"chrome"})`, mở `https://adstransparency.google.com/?region=anywhere`, `rpc` = `page.evaluate(fetch POST form f.req)` cùng nguồn, kiểm `isBlockedResponse` (cả khi trang tự chuyển sang /sorry); ảnh hình: tải qua `context.request`; chữ/video: trang trắng `about:blank`, chèn `<div id=…>` + script content.js với `htmlParentId`/`responseCallback` đúng tham số URL, chờ ≤10 s, chụp phần tử; lỗi → null.
- `bin/scan.js`: `withLock(data/.scan.lock)` → `openChromeClient` → `runScan` → `syncToGitHub(root)` (Task 4) → đóng.
- [ ] Test với client giả: lượt đầu dừng ở 5 trang; lượt sau dừng khi trang không mới; `BlockedError` ở đối thủ thứ 2 → status `blocked`, đối thủ 1 vẫn được lưu, nhật ký có `blocked`; `lock prevents concurrent scan`. FAIL → mã → PASS → commit.

### Task 3: máy chủ + giao diện
**Files:** Create `src/server.js`, `bin/server.js`, `web/index.html`, `web/app.js`, `web/style.css`, `tests/server.test.js`.
**Interfaces — Consumes:** Store (Task 1). **Produces:** `startServer({store, port=4317, host="127.0.0.1", triggerScan:()=>Promise, isScanning:()=>boolean}) -> Promise<http.Server>`.
API: `GET /api/profiles`, `POST /api/profiles {name}`, `GET|POST /api/profiles/:pid/watchlist {input, region}`, `DELETE /api/profiles/:pid/watchlist/:wid`, `GET /api/profiles/:pid/ads?filter&q&format`, `GET /api/status -> {scanning, last}`, `POST /api/scan` (409 nếu đang quét), tĩnh `web/`, `/images/*` từ `store.imagesDir()` (chặn `..`). `bin/server.js` gọi `bin/scan.js` như tiến trình con cho `triggerScan`.
UI: bố cục 3 cột ngang theo spec (≥1280px; dưới đó cuộn ngang, không xếp dọc), nhớ hồ sơ đang chọn (localStorage có try/catch), lưới thẻ ảnh, khung chi tiết, thanh trạng thái + nút Quét ngay (thăm dò /api/status 5 s khi đang quét).
- [ ] Test API bằng `fetch` trên cổng ngẫu nhiên với store thư mục tạm: tạo hồ sơ, thêm/xoá đối thủ, lỗi 400 chữ tiếng Việt khi input sai, 409 khi đang quét, `/images/../package.json` → 404. FAIL → mã → PASS → commit.

### Task 4: đồng bộ GitHub + cài trên macOS
**Files:** Create `src/sync.js`, `ops/install-macos.sh`, `ops/uninstall-macos.sh`, `README.md` (tiếng Việt), `tests/sync.test.js`.
**Produces:** `syncToGitHub(root) -> Promise<{pushed:boolean, reason?}>` — `git add data && git commit -m "Dữ liệu quét <ISO>" && git push`, không bao giờ ném; không có gì đổi → `{pushed:false, reason:"không đổi"}`.
